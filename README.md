# MonitoraRibeirao

Projeto de monitoramento de ativos de rede desenvolvido em PowerShell com foco em automação, observabilidade e aprendizado contínuo.

## Funcionalidades

- Monitoramento ICMP
- Hosts online/offline
- Latência
- Dashboard visual
- Logs operacionais

## Tecnologias

- PowerShell
- Git
- GitHub

## Objetivo

Projeto pessoal voltado para aprendizado de automação, monitoramento e boas práticas de infraestrutura utilizando PowerShell.

│

└── README.md
